# Vibe Cursor

A playful Chrome extension that reskins any page to match a vibe and drops compliments as your cursor moves.

## Features (in progress)

- Mood-based page skin (calm, hype, cozy, chaotic) via CSS filters
- Compliment-dropping cursor trail
- Popup UI to toggle the vibe on/off and pick a mood
- Preferences saved with `chrome.storage.local`

## Load it locally

1. Open `chrome://extensions`
2. Enable "Developer mode"
3. Click "Load unpacked" and select this folder
